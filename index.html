  • 01 · 영상

    숏폼·홍보 영상

    인스타그램 릴스, 유튜브 쇼츠, 틱톡에 올릴 세로 영상을 만듭니다.

    • 가게·상품 소개 숏폼
    • 광고용 짧은 영상
    • 자막·배경음악 편집
  • 02 · 이미지

    홍보 이미지

    SNS 게시물, 상세페이지, 메뉴판·안내물에 쓸 이미지를 만듭니다.

    • SNS 게시물·카드뉴스
    • 상품·메뉴 이미지
    • 배너·썸네일
  • 03 · 웹

    소개 홈페이지

    휴대폰에서 바로 열리는 가게·브랜드 소개 홈페이지를 만듭니다.

    • 한 페이지 소개 사이트
    • 위치·영업시간·문의 연결
    • 도메인 연결 안내

PULSR에 맡기는 이유

  • 한곳에서 끝납니다

    영상·이미지·홈페이지를 따로 알아볼 필요 없이 같은 사람이 같은 톤으로 만듭니다.

  • 만드는 사람이 직접 답합니다

    중간 영업 담당 없이 제작자가 메일로 직접 상담하고 수정 요청을 받습니다.

  • 우리 채널도 직접 운영합니다

    PULSR는 자체 SNS 채널(쇼츠·화보 등)을 직접 운영하며 플랫폼별 형식을 다룹니다.

진행 순서

  1. 1메일로 문의무엇을, 어디에 쓰실지, 원하시는 일정을 적어 hello@pulsr.kr 로 보내 주세요.
  2. 2범위·견적 회신만들 범위, 일정, 금액, 수정 횟수를 정리해 메일로 답장드립니다.
  3. 3시안 확인합의한 범위로 시안을 만들어 보여 드리고 의견을 받습니다.
  4. 4수정·납품합의한 횟수 안에서 고친 뒤 최종 파일 또는 사이트 주소로 드립니다.
